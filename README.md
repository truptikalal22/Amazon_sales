# Amazon Sales Analysis

This project is a simple data analysis of Amazon sales data using Python. The goal was to explore the dataset, clean the data, visualize important trends, 
and extract meaningful business insights that can help understand customer purchasing behavior and product performance.

## Project Objectives

- Clean and preprocess the dataset
- Explore sales data using Python
- Analyze product ratings and discounts
- Identify top-performing categories and products
- Visualize trends using charts
- Generate business insights from the data

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Loaded the dataset
2. Cleaned missing and duplicate values
3. Performed exploratory data analysis (EDA)
4. Created visualizations
5. Summarized key business findings

## Key Insights

- Some product categories contribute significantly more sales than others.
- Products with higher ratings generally receive more customer engagement.
- Discounts influence purchasing behavior, but larger discounts do not always lead to better ratings.
- A small number of products generate a large portion of overall sales.

## How to Run

Clone the repository:

```bash
git clone https://github.com/truptikalal22/Amazon_sales.git
```

Move into the project folder:

```bash
cd Amazon_sales
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and run the cells to reproduce the analysis.
